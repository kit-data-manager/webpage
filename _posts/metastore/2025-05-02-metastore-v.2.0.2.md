Today, we like to announce version 2.0.2 of the MetaStore service. Below, you can find the list of changes. 

## New Features
* Allow to restrict access to POST endpoints by @github-actions in [PR 671](https://github.com/kit-data-manager/metastore2/pull/671)

## Bugfixes
* /actuator endpoints shouldn't be exposed by default by @github-actions in [PR 683](https://github.com/kit-data-manager/metastore2/pull/683)
* "Write" permission doesn't allow to edit resources in MetaRepo by @github-actions in [PR 692](https://github.com/kit-data-manager/metastore2/pull/692)
