Today, we like to announce the new release v1.5.8 of base-repo. This release mainly contains bugfixes and security updates. 
If you face any new issues, please tell us via the [Issue Tracker](https://github.com/kit-data-manager/base-repo/issues).

## New Features
* ACL information no longer removed for Non-Administrator Users by @github-actions in https://github.com/kit-data-manager/base-repo/pull/381
* Resources with state GONE are now visible to owners and administrators (introduced in repo-core v1.2.5)
